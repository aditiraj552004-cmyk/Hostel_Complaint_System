# 🏠 HostelCare – Smart Hostel Complaint Management System

HostelCare is a full-stack web application designed to simplify hostel complaint management. It enables students to report issues, track complaint status, and receive updates, while providing hostel administrators with a centralized dashboard to manage and resolve complaints efficiently.

---

## 📌 Project Overview

Traditional hostel complaint systems are often manual, resulting in delayed responses and poor communication. HostelCare digitizes this process by providing a transparent and user-friendly platform for students and administrators.

---

## ✨ Features

### 👨‍🎓 Student
- User Registration & Login
- Submit Complaints
- Upload Complaint Images
- Track Complaint Status
- View Complaint History
- Update Profile
- Submit Feedback

### 👨‍💼 Admin
- Secure Admin Login
- View All Complaints
- Update Complaint Status
- Search & Filter Complaints
- Dashboard Analytics
- User Management

## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/hostel-complaint-system.git
```

### Frontend

```bash
cd client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
npm start
```
